# 50 Days 50 Projects

This repository documents a personal challenge to build one **HTML, CSS, and JavaScript** project every day for 50 consecutive days. Each project focuses on a specific frontend concept, ranging from layout and styling fundamentals to interactive behavior and basic application logic.

The goal of this challenge is to improve consistency, reinforce core web development skills, and build a diverse collection of small, focused projects. Each day’s project is self-contained and designed to be completed within a limited time frame, emphasizing clarity, experimentation, and incremental improvement.
